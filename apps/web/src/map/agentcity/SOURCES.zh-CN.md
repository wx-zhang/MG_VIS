# 地图渲染模块来源

从用户指定的本地 `agentcity`（`qee@64ae5aa`）迁移，原始目录为 `src/components/map/`。保留建筑立面、屋顶、道路、水面、桥梁、树木、环境光、接触阴影和缩放 LOD 的算法。适配范围为 React 生命周期、注入 Workspace 建筑位置、移除 Vue/Mock 业务依赖与无地形源兼容。建筑尺寸提取为轻量 `organizationProfile.ts`，供模型与点击区域共享；阴影常量适配当前 Three.js 的 `PCFShadowMap`。

本次不复制其越南地理数据、机构数据、业务模拟、人物模型或纹理素材。Marlow Green 地图数据由本项目的可复现脚本生成，明确为虚拟城市。投影中心与参考渲染模块一致，仅作为局部坐标计算锚点，不表示组织真实位置。
